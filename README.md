# Fa venir SALIVERA · v1.3

Biblioteca personal de restaurants, receptes, vins, botigues i experiències preparada per GitHub Pages i PWA.

## Novetats v1.3

- Mòdul de mapa general de restaurants.
- Dos mapes diferenciats: Països Catalans i Altres territoris.
- Els marcadors obren la fitxa completa del restaurant.
- El mapa individual deixa d'aparèixer dins de cada fitxa.
- Filtre Vegueria: només vegueries dels Països Catalans i ALTRES.
- En seleccionar ALTRES, Zona mostra Espanya, França, Irlanda i altres països disponibles.
- Noms de cuina sempre en majúscules.
- Espai d'administració per crear vegueries, zones vinculades a una vegueria, cuines i categories.
- Les opcions creades a administració es desen al navegador amb localStorage.

## Publicació

Puja tot el contingut d'aquesta carpeta a l'arrel del repositori de GitHub Pages.
